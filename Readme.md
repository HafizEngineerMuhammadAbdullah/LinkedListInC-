# Linked List in C

A complete collection of Linked List programs implemented in C++ language for learning Data Structures and Algorithms (DSA).

This repository contains different Linked List concepts, operations, and problem-solving implementations written during my DSA learning journey.

---

## 📚 Topics Covered

### ✅ Singly Linked List

* Creation of Linked List
* Insertion Operations

  * Insert at Beginning
  * Insert at End
  * Insert at Specific Position
* Deletion Operations

  * Delete from Beginning
  * Delete from End
  * Delete Specific Node
* Traversal / Display
* Searching in Linked List
* Counting Nodes
* Updating Nodes
* Reversing Linked List

---

### ✅ Doubly Linked List

* Creation
* Forward Traversal
* Backward Traversal
* Insertion Operations
* Deletion Operations

---

### ✅ Circular Linked List

* Creation
* Traversal
* Insertion
* Deletion

---

### ✅ Important Linked List Problems

* Reverse Linked List
* Find Middle Node
* Detect Loop
* Remove Loop
* Merge Linked Lists
* Slow & Fast Pointer Approach
* And more...

## 🚀 How to Run the Programs

### Step 1:

Clone the repository

```bash
git clone https://github.com/HafizEngineerMuhammadAbdullah/LinkedListInC-.git
```

### Step 2:

Open the project folder

```bash
cd LinkedListInC-
```

### Step 3:

Compile the program

```bash
gcc filename.c -o output
```

### Step 4:

Run the program

```bash
./output
```
